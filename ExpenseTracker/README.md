# 💰 Expense Tracker

A clean and professional desktop Expense Tracker built using **Python, PyQt5, and SQLite**.

The application allows users to record, view, edit, delete, and analyze their expenses through a simple and modern graphical interface.

## ✨ Features

- 📊 Dashboard with expense statistics
- ➕ Add new expenses
- 🧾 View all expenses
- ✏️ Edit existing expenses
- 🗑️ Delete expenses
- 📈 Category-wise spending analytics
- 💾 SQLite database for data persistence
- 🔄 Refresh expense data
- 📅 Expense date selection
- 💰 Indian Rupee (₹) support
- 🎨 Clean and modern PyQt5 interface

## 🛠️ Technologies Used

- **Python**
- **PyQt5**
- **SQLite**
- **Qt Stylesheets (QSS)**
