# Gemini Voice Studio 🎙️

A clean and simple desktop Text-to-Speech application powered by
Google Gemini TTS.

## Features

- 🎙️ Gemini AI voice generation
- 🗣️ Multiple preset voices
- 🌎 Accent control
- 🎭 Speaking style control
- ⚡ Speaking speed control
- 💾 Save generated audio as WAV
- 🌑 Clean dark GUI
- 🚀 Non-blocking background generation
- 🔐 API key stored using environment variables

## Tech Stack

- Python
- Tkinter
- Google Gemini API
- Gemini TTS
- python-dotenv
